## 📅 진행 방식

- **일시**: 매주 수요일 저녁
- **발표**: 매주 1명씩 돌아가며 **5~10분** 알고리즘 개념 발표
- **문제**: 각자 준비한 문제 질의응답
- **문제 풀이**: 매주 지정된 문제를 미리 풀어온 뒤 함께 리뷰

## ✅ 스터디 규칙

- 발표자는 해당 주차의 핵심 개념을 **5~10분** 동안 발표합니다.
- 모든 스터디원은 지정된 문제를 미리 풀어옵니다.
- 이슈에 시간복잡도, 풀이 방법, 의사코드를 작성합니다.

## 📚 문제 구성

매주 총 **5문제**

| 플랫폼 | 난이도 |

| [Programmers](https://school.programmers.co.kr/learn/challenges) | Lv.2 ~ Lv.3 (정답률 40% 이상) |

| [Codetree](https://www.codetree.ai/ko/frequent-problems) | 적정 난이도 선정 |

## 💡 Git 컨벤션

### 이슈/PR

- 문제별 이슈를 생성하면, 댓글로 **시간복잡도, 풀이 아이디어, 풀이과정**을 작성합니다.
- 매주 스터디가 끝나면 PR을 올려서 `main` 브랜치에 merge합니다. 

### 커밋 메시지
```text
이름: 문제 번호 문제 이름
```

- 예시

```text
신예지: S1954 달팽이 숫자
```

### 브랜치

- 브랜치는 **GitHub 닉네임**으로 생성합니다.

### 디렉토리 구조

```text
주차/
└── S문제번호 또는 P문제번호/
    └── 이름이니셜_S문제번호.java
    └── 이름이니셜_P문제번호.java
```

- 예시

```text
1주차/
├── S1234/
│   ├── YJ_S1234.java
│   └── GE_S1234.java
└── P56789/
    ├── YJ_P56789.java
    └── GE_P56789.java
```

- `S` : SWEA
- `P` : 프로그래머스
- `C` : Codetree
- 파일명은 `이름이니셜_문제번호` 형식을 사용합니다.
